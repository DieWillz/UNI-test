# Юни — пользовательский интерфейс

Автономный прототип двух режимов одного desktop-overlay:

- **Быстрая задача** — диалог, подзадачи, живой статус и результат.
- **Длительная миссия** — этапы, последние действия, подтверждённый результат, затраты и ожидание решения.

## Запуск

Откройте `index.html` в современном браузере. Сервер и сборка не требуются.

## Файлы

- `index.html` — семантическая структура обоих режимов.
- `styles.css` — дизайн-токены, стекло, адаптивность и состояния.
- `app.js` — интерактивность и публичный мост для backend/Electron.

## Подключение к Юни

Интерфейс экспортирует `window.UNIInterface`:

```js
UNIInterface.setMode('quick');
UNIInterface.setQuickTask({ action: 'Открываю браузер…', progress: 25 });

UNIInterface.setMode('mission');
UNIInterface.setMission({ action: 'Сравниваю 6 вариантов…', percent: 38 });
UNIInterface.setStatus('Жду подтверждения', 'waiting');
UNIInterface.setAvatar('done');
```

События интерфейса:

- `uni:message` — пользователь отправил текст;
- `uni:stop` — STOP/продолжение;
- `uni:mode-change` — смена режима.

## Аватар

В комплекте используется CSS-fallback, поэтому прототип работает автономно. Для production замените содержимое `.avatar-art` на ваши PNG/WebP/VRM-состояния: `idle`, `listening`, `working`, `waiting`, `done`. Контейнер и логика состояний уже готовы.

## Важная продуктовая логика

- Живой статус обновляется одной строкой.
- STOP и наблюдение всегда видимы.
- Ожидаемые деньги не смешиваются с подтверждёнными.
- Перед внешними публикациями, расходами и договорами показывается запрос решения пользователя.
