Как работает применение

    
Сразу: политика агента, автономность, лимиты Dorch и другие параметры, которые runtime читает из общего Config.

    
После перезапуска: модель, браузер, устройства ввода/вывода, STT/TTS, камера и Vision — они создаются при старте capability.

    
DOM/UIA и OCR используются раньше VLM. Vision остаётся резервным смысловым слоем для сцен, изображений и элементов без читаемого текста.
