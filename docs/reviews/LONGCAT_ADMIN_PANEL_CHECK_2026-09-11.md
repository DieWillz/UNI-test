# UNI — Визуальная проверка через Админку

**Дата:** 2026-09-11  
**Автор:** Longcat (Hermes Agent)  
**Цель:** Проверить функции Юни через веб-панель как реальный пользователь

---

## Как проверять

1. Запустите сервер: `cd C:\LLM\UNI && set PYTHONPATH=C:\LLM\UNI && C:\LLM\python312\python.exe -m uni.webui`
2. Откройте браузер: `http://127.0.0.1:8787`
3. Для каждой функции используйте указанный endpoint через вкладку "Компьютер" или через curl/Postman
4. Отмечайте ✅ если видите ожидаемый результат, ❌ если нет

---

## 1. Управление компьютером (Computer)

### 1.1. Список видимых окон

**Endpoint:** `POST /api/computer/act`  
**Тело:** `{"goal": "list_visible_windows"}`

**Что увидеть:** Список окон с заголовками в ответе.

**Критерий:** ✅ Если в списке есть открытые окна

---

### 1.2. Открыть приложение

**Endpoint:** `POST /api/computer/act`  
**Тело:** `{"goal": "открой блокнот"}`

**Что увидеть:** Открылось окно Блокнота.

**Критерий:** ✅ Если Блокнот появился на экране

---

### 1.3. Открыть сайт

**Endpoint:** `POST /api/computer/act`  
**Тело:** `{"goal": "открой сайт example.com"}`

**Что увидеть:** Открылся браузер со страницей example.com.

**Критерий:** ✅ Если страница загрузилась

---

### 1.4. Поиск в интернете

**Endpoint:** `POST /api/computer/act`  
**Тело:** `{"goal": "найди в интернете погода москва"}`

**Что увидеть:** Открылась страница поиска с результатами.

**Критерий:** ✅ Если результаты поиска отображаются

---

## 3. Зрение (Vision)

### 3.1. Снимок с камеры

**Endpoint:** `POST /api/vision/capture`

**Предусловие:** Камера должна быть запущена через `/api/camera/start`

**Что увидеть:** Фото с камеры сохраняется на диск.

**Критерий:** ✅ Если файл появился

---

### 3.2. Анализ экрана

**Endpoint:** `POST /api/vision/observe`  
**Тело:** `{"prompt": "Опиши что на экране"}`

**Предусловие:** Должен быть запущен VLM (LM Studio/Gradio) и дано согласие (consent)

**Что увидеть:** Текстовое описание содержимого экрана.

**Критерий:** ✅ Если описание соответствует реальности

---

## 4. Голос (TTS)

## 5. Автономный режим

**Критерий:** ✅ Если режим запустился (running: true)

### 5.2. Остановка автономного режима

**Что увидеть:** Юни прекращает автономные действия.

**Критерий:** ✅ Если режим остановился

### 6.2. Клик по координатам

## 10. Известные проблемы (на момент проверки)

| Проблема | Endpoint | Описание |
|----------|----------|----------|
| Таймаут чата | `/api/chat` | Если LLM не отвечает — таймаут |
| Таймаут STT | `/api/stt/listen` | Если Whisper не загружен — таймаут |
| Ошибка камеры | `/api/vision/capture` | Камера не запущена |
| Consent | `/api/vision/observe` | Требуется согласие на наблюдение |
| Intiface | `/api/autonomous/stop` | Ошибка если Intiface не подключен |
| Computer capability | `/api/click_at`, `/api/set_mouse_mode` | Computer capability недоступен |
