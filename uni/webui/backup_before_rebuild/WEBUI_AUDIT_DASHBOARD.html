P0 CRITICALjs/app.js — минифицированный монолит

~100KB в одну строку, абсолютно нечитаемый. Ссылается на несуществующий файловый сервер :8000 (Qwen legacy). Дублирующиеся функции (startVoiceLoop, setRole объявлены 2-3 раза).

// Дублирующиеся функции:
function startVoiceLoop(){...}  // объявлена 2 раза
function setRole(name){...}     // объявлена 3 раза
let FS='http://127.0.0.1:8000'  // сервер не существует!
P0trajectories.jsonl — фейковая фикстура

128 KB, сотни идентичных записей, только 4 координаты повторяются: (140,115), (15,15), (950,520), (20,20). 100% фейковый success rate. Самоулучшение обучается на шуме.

// Анализ файла:
coordinates: 4 уникальных значения
goals: "открой блокнот", "цель"
success_rate: 100% (подозрительно)
verdict: FAKE FIXTURE
P0handlers/memory_facts.py — неверный путь

Ищет memory/working.json в корне проекта, но реальный путь uni/memory/working.json. Эндпоинт /api/memory/facts возвращает пустые данные.

# handlers/memory_facts.py
_WORKING = _ROOT / "memory" / "working.json"  # ❌
# должно быть:
_WORKING = _ROOT / "uni" / "memory" / "working.json"  # ✅
P0admin_api.py — 5 правок без тестов

Qwen (16.08) исправил 5 строк (пути bridge/outbox, import sys, glob, vision_capture), но без pytest/py_compile. Нет shell-доступа у автора правки — синтаксис не проверен.

<script src="app.js"> работает только благодаря _STATIC_ALIASES в server.py. Любое изменение server.py может сломать статику.

✅ Создана новая админка v4

Один самодостаточный файл index.html (28 KB) со встроенными CSS и JS. Не зависит от js/app.js.

  • Адаптивная вёрстка (mobile-friendly)
