# Админка UNI — интеграция v4 в основную панель

Дата: 2026-08-16. Автор: Hermes.

## Что сделано
Фичи админки v4 (webui/v4/) **внедрены в основную корневую админку**
(webui/index.html + webui/js/app.js + webui/css/style.css) аддитивно, без
замены старых разделов. Старая админка осталась рабочей (Dorch L4, Браузер,
Передача данных и т.д.), добавились новые вкладки «Админ v4».

## Новые вкладки (в сайдбаре, группа «🛠 Админ v4 (новый)»)
- 📊 Обзор v4 — стек (llama/webui/launcher/electron), железо, git, статистика
- 👥 Агенты v4 — heartbeat всех ИИ
- 📜 Логи v4 — /api/uni/logs (источник + фильтр уровня)
- 📋 Задачи и фазы v4 — backlog, фазы, блокировки
- 📓 Журнал событий v4 — UNI_JOURNAL.jsonl
- 📄 Отчёты v4 — список + содержимое отчётов из outbox/bridge
- 🧰 Инструменты v4 — STOP, СТОП цикла мыши, Демо мыши, Самотест, pytest,
  Арх-аудит, Скриншот, Рестарт WebUI
- 👁 Мышь и зрение v4 — consent + наблюдение
- ⚡ Автономность v4 — статус + старт/стоп
- 🔌 XToys / Intiface v4 — статусы устройств
- ⚙ Настройки v4 — sanitized дамп /api/config

## Ключевая фича: честные бейджи статуса
Каждый блок показывает реальный статус:
- 🟢 b-ok — данные есть и валидны
- 🟠 b-warn — НЕТ ДАННЫХ / ВЫКЛЮЧЕНО
- 🔴 b-err — ошибка fetch/API
- 🔵 b-info — НЕ ПРОВЕРЕНО (нужна живая среда)
- 🟣 b-stub — НЕ РЕАЛИЗОВАНО

## Файлы
- `uni/webui/js/admin_v4.js` — НОВЫЙ изолированный модуль (IIFE, все имена
  префиксованы `v4*`, чтобы не конфликтовать с каноном `js/app.js`).
- `uni/webui/index.html` — добавлены nav-кнопки + 11 `view-wrap` секций
  (id `view-v4_*`) + подключение `<script src="admin_v4.js">`.
- `uni/webui/css/style.css` — добавлены стили `.v4-*` (используют переменные
  канона, вписываются в светлую/тёмную тему).
- `uni/webui/server.py` — добавлен алиас `/admin_v4.js` → `js/admin_v4.js`
  в `_STATIC_ALIASES` (аддитивно).

## Как проверить
1. Открыть `http://127.0.0.1:8787/` (корневая админка).
2. В сайдбаре найти группу «🛠 Админ v4 (новый)», кликнуть любую вкладку.
3. Данные грузятся из реальных API; бейджи показывают статус.
4. Старая админка (Dorch L4 и т.д.) остаётся доступна выше по сайдбару.

## Примечания
- Старая версия также доступна по `/v3/` (туда скопирована v4 как legacy).
- `/v4/` по-прежнему отдаёт автономную версию v4 (дубликат, можно удалить
  по решению координатора).
- Не удалено и не переименовано ни одного существующего файла.
