# UNI Desktop Companion (оверлей) — Дизайн-док

**Статус:** MVP-каркас (Hermes SOLO, 2026-08-11).  
**Концепт (от создателя):** прозрачный десктоп-оверлей поверх всех окон с
полноростовым аватаром-компаньоном, чатом и **проактивностью** (Юни сама видит
экран и инициирует диалог/действия по уровням автономии).

## 1. Архитектура (три слоя)
```
СЛОЙ 1: Оболочка (Electron)  — прозрачное frameless окно, always-on-top, трей,
                              click-through по альфе, глобальные хоткеи.
СЛОЙ 2: Аватар (2D спрайты → 3D VRM) — индикатор состояния (idle/talk/listen/think/stop).
СЛОЙ 3: UI-панели — чат, настройки, согласие (consent), роли, уровень автономии.
        │ HTTP/SSE → 127.0.0.1:8787 (server.py, без изменений существующих эндпоинтов)
КАНОН:  /api/chat, /api/tts, /api/roles, /api/safety, /api/autonomous/stream,
        + НОВЫЕ (аддитивно): /api/stt, /api/desktop/events, /api/desktop/consent
```

## 2. Компоновка окна (из прототипа создателя)
```
┌──────────────────────────────────────────────────────┐
│  (прозрачно — рабочий стол виден)                    │
│  ┌──────────────────┐                 ╭──────────╮    │
│  │ ⚙ 👁 🎚 🛑 (кнопки: │                 │  Юни    │    │
│  │  настройки, зрение,│                 │ полный  │    │
│  │  автономия, стоп,  │                 │ рост,   │    │
│  │  скрыть)           │                 │ у кромки│    │
│  ├──────────────────┤                 ╰──────────╯    │
│  │ ЧАТ с Юни          │                                │
│  └──────────────────┘                                 │
└──────────────────────────────────────────────────────┘
```
- Клики по прозрачным зонам проходят сквозь (click-through).
- Аватар и панель перетаскиваются; панель сворачивается; аватар у нижней кромки.

## 3. Проактивность (новый блок, по манифесту v2.6)
Непрерывное наблюдение — **только при явном согласии** (`/api/desktop/consent`)
и с постоянным видимым индикатором. Привязано к уровням автономии (`/api/safety`):
- `off` — ничего; `observe` — молча видит; `suggest` — начинает диалог/подсказку;
  `act` — действия из белого списка (через `act_on_screen`), остальное с подтверждением.
- Цепочка: захват экрана (раз в 5–15с) → лёгкий локальный анализ (UIA/OCR) →
  детектор событий → инициатива (пузырь/голос) или действие → журнал.
- Защита от назойливости: бюджет инициатив (N/час), «не беспокоить», пауза по «стоп».

## 4. Бэкенд (добавлено аддитивно, не ломая канон)
- `POST /api/stt` — принимает аудиофайл (multipart), возвращает `{"text": ...}`.
  Использует `uni/capabilities/stt.py` (опциональный Whisper; если недоступен — 501).
- `GET /api/desktop/events` — SSE: события для оверлея (смена уровня автономии,
  инициатива, статус наблюдения). Реализован на базе паттерна `/api/autonomous/stream`.
- `GET/POST /api/desktop/consent` — получить/установить согласие на наблюдение;
  пишет журнал согласий (`memory/consent_log.jsonl`).

## 5. Оболочка (Electron MVP)
- `package.json` — зависимость `electron` (ставится на целевой машине).
- `main.js` — `transparent:true, frame:false, alwaysOnTop, skipTaskbar`, трей,
  `setIgnoreMouseEvents` по hit-test альфы, глобальный PTT-хоткей, SSE-клиент.
- `index.html` + `style.css` + `app.js` — рендерер (чат, аватар, кнопки, SSE).

## 6. Этапы (DC-задачи)
- DC-01 Дизайн-док (этот файл).
- DC-02 `/api/stt` (опциональный Whisper).
- DC-03 `/api/desktop/events` (SSE).
- DC-04 `/api/desktop/consent` (согласие + журнал).
- DC-05 Electron main.js (прозрачность, click-through, трей, PTT).
- DC-06 Renderer: index.html + style.css (компоновка из прототипа).
- DC-07 Renderer app.js (чат, TTS, SSE, кнопки, PTT→/api/stt).
- DC-08 Тесты `test_api_desktop.py` (реальный сервер).
- DC-09 Зеркалирование + коммит + пуш + отчёт.
- DC-10..12 (будущие): 3D VRM (three-vrm), детектор событий наблюдения,
  миграция на Tauri (опц.).

## 7. Риски (решать на реальной машине)
- Прозрачность/click-through на Windows 10; GPU-бюджет (LM Studio на 3060 12GB);
- карта хоткеев (не конфликтовать с AHK Ctrl+Alt+* и Ctrl+Alt+Shift+U kill-switch);
- приватность скриншотов (только локально, индикатор, срок хранения).
