# UNI — голосовой AI‑помощник для XToys.app

Говорите команды, UNI слушает, думает, отвечает и управляет устройством.

ВАЖНО: репозиторий недавно очищён от локальных профилей, кэшей и больших бинарных файлов.
Если вы работали с ранними версиями репозитория, сделайте fresh clone (см. «Обновление репозитория»).

## Установка

```bash
python -m pip install -r requirements.txt
playwright install chromium
```

Примечание: зависимости разделяются на базовые и опциональные (speech/vision/tts). Для CI/тестов установите только необходимые пакеты.

## Запуск

```
python -m uni
```

## Команды (пример)

- "Открой xtoys" — открывает сайт
- "Включи устройство" — включает устройство
- "Выключи устройство" — выключает устройство
- "Установи интенсивность 70" — двигает слайдер
- "Выбери паттерн волна" — выбирает паттерн
- "Какой статус?" — спрашивает статус (если включена Vision)

## Что изменено в этой ветке / репозитории

- Удалены из истории и индекса локальные браузер‑профили и кеши (.uni-yandex-council-profile, .uni-browser-profile, .uni-council-browser-profile), локальные логи и голосовые сэмплы.
- Большие двоичные файлы (*.onnx, *.tflite, *.exe, *.dll, *.crx, *.zip, *.tar и т.д.) исключены из истории и теперь трекаются через Git LFS (если требуется).
- Выполнён git gc и принудительный push (history rewrite). Если у вас есть локальные клоны — сделайте fresh clone или синхронизируйте согласно инструкции ниже.

## Обновление репозитория (ВАЖНО после force‑push)

Чтобы синхронизировать рабочую копию после переписанной истории, в существующих локальных клонов выполните (стоящая работа сохранена отдельно):

```
git fetch origin --prune
git checkout main
git reset --hard origin/main
```

Лучше всего: удалить локальный клон и клонировать заново:

```
cd ..
rm -rf UNI-test
git clone https://github.com/DieWillz/UNI-test.git
```

## Секреты

- Ни в коем случае не храните API‑ключи в `config.yaml`. Используйте переменные окружения, OS secret store (Windows Credential Manager) или `.uni-local/secrets.yaml` (неотслеживаемый файл).
- В веб‑интерфейсе показывайте только наличие ключа и последние 4 символа.

## Хранение больших моделей

- Переместите модели и большие бинарники в Git LFS или внешнее хранилище (S3, Artifacts). См. `.gitattributes`.

## CI

Рекомендуется настроить GitHub Actions для автоматического запуска `scripts/check_architecture.py` и тестов (`pytest`) на PR.

## Контакты / Если что-то пошло не так

Если вы столкнулись с проблемами после force‑push — напишите владельцу репозитория или выполните fresh clone, как описано выше.
