## Шаг 1 — один провайдер, один реальный раунд, без демо-режима

Цель: не «красивый интерфейс», а один настоящий цикл запрос→ответ через реальный API, без фейковых данных.

- Взять **одного** провайдера с подтверждённым рабочим ключом — судя по журналу, это либо локальный Hermes (LM Studio на 127.0.0.1:1234), либо Groq (был статус `рабочий` в последней проверке).
- Через `devcoord` или `council` (смотря какой модуль реально исполняется, см. шаг 0) прогнать один раунд: один вопрос → один реальный ответ → запись в файл.
- **Definition of done:** в терминале виден реальный HTTP-запрос и реальный текстовый ответ от модели, не строка из `FALLBACK_AGENTS`.

Это самый важный шаг — если он не пройден, всё остальное строится на песке.

Не переписывать консоль заново — она уже собрана (index.html/script.js/style.css из предыдущих сообщений). Задача — довести её до того, чтобы `BACKEND_OK` было `true`, а не падало в демо-режим.

- **Definition of done:** нажал «Запустить раунд» в браузере → увидел реальный ответ реальной модели в сетке, не заглушку.

## Шаг 3 — добавить второго и третьего провайдера, по одному, с проверкой каждого

Не «настроить всех сразу» — по одному, потому что именно так вскрылись реальные проблемы (OpenRouter 403, Gemini 404 из прошлого разбора). Каждый провайдер добавляется только после того, как для него подтверждён живой ответ, а не после того, как вписан в config.yaml.

Порядок по надёжности (дешевизна/бесплатность в приоритете):
1. Gemini Flash (бесплатный тир, но проверить актуальный `model_id` — в прошлый раз `gemini-1.5-flash` давал 404, модель снята).
2. DeepSeek через API (платно, но копейки) — если нужен реальный API-доступ, а не веб-чат.
3. OpenRouter — только после того, как подобран рабочий `:free`-id вместо текущего 404.

**Браузерные участники (DeepSeek/QWEN/Claude/Grok через веб-чат) я сознательно не включаю в core MVP** — автоматизация их веб-интерфейсов без официального API, скорее всего, нарушает условия использования этих сервисов, я отказывался это строить раньше и позиция не меняется. Если хочешь их держать в проекте — это отдельная, опциональная и ручная часть («скопировать вопрос → вставить в веб-чат → скопировать ответ» — то, чем ты и занимался изначально), не автоматизированный core.

## Шаг 4 — структурированный сбор данных (то, ради чего всё затевалось)

- Каждый раунд пишется не только в лог, но и в структуру, которую можно потом скормить обратно в разработку UNI: тема, участник, ответ, `decision` (ACCEPT/REJECT), `source_verified`.
- Это уже частично спроектировано (Coverage/Responses таблица, `DevelopmentTask`/`CoordinationStore` в `devcoord`) — не изобретать заново, свести к одному формату хранения.
- **Definition of done:** после 5 раундов можно открыть файл истории и увидеть 5 структурированных записей, а не 5 строк в чате, которые придётся искать вручную.

## Шаг 5 — «автоматический режим» разработки кода UNI

Здесь важно точно определить, что значит «автоматически», потому что есть два разных сценария:

**А. Автоматический сбор мнений/ревью** (модели анализируют код, дают рекомендации) — это то, что мы уже делаем этим самым файлом-планом. Автоматизировать полностью можно: скрипт берёт diff/файл, шлёт всем настроенным провайдерам, складывает ответы в Coverage/Responses. Это безопасно автоматизировать целиком.

**Б. Автоматическое применение изменений к коду UNI** — это должно **оставаться с ручным гейтом**, и вот почему конкретно, не абстрактно: в этом самом разборе кода источники давали друг другу противоречащие фактические утверждения о содержимом одних и тех же файлов (есть ли `debug=True` в конфиге, используется ли `planner.py` в рантеме). Если позволить моделям автоматически коммитить правки без проверки человеком — ошибочное «исправление» несуществующей проблемы попадёт в код первым, а не будет отловлено сравнением с реальным файлом. Схема: агенты предлагают патч → он идёт в PR/diff → ты (или следующий раунд с явным указанием «прочитай файл перед ответом») подтверждаешь → мерж. Не полная автономность.

## Что явно не входит в MVP (сознательно, не забыл)

- Красивый продуктовый GUI поверх нестабильного ядра — сначала стабильность (шаги 0–3), интерфейс уже есть и его достаточно.
- Браузерная автоматизация платных ИИ-сервисов — ToS-риск, не строю.
- Полностью автономный мёрдж кода без ревью — риск на основании уже увиденных противоречий между источниками.
- `SiteProfile`, Dual-Mode курсора, векторная память и прочее из P2/P3 плана — полировка, делать после того, как шаги 1–4 реально работают.

### Этап 1: Архитектура MVP "UNI Council" (Бэкенд)
*Создаем модуль, который будет оркестровать общение с ИИ. В `README` указана папка `uni/council/` — туда и кладем логику.*

**1. Единый интерфейс адаптеров (Adapters)**
Создаем базовый класс для всех ИИ-участников, чтобы Council мог общаться с ними в едином формате.
```python
# uni/council/adapter.py
from typing import AsyncGenerator

class BaseAIAdapter:
    name: str
    async def generate(self, prompt: str, system: str) -> AsyncGenerator[str, None]:
        raise NotImplementedError
```
*Реализации:* `LMStudioAdapter` (использует ваш `uni.brain`), `OpenAIApiAdapter`, `ClaudeApiAdapter` (чтобы подключать "внешних" участников).

**2. Менеджер Совета (Council Manager)**
Принимает задачу, делает широковещательную рассылку (broadcast) всем подключенным адаптерам асинхронно через `asyncio.gather`.
```python
# uni/council/manager.py
async def run_council(self, task: str) -> list[ParticipantResponse]:
    # Запускаем всех ИИ параллельно
    results = await asyncio.gather(*[ai.generate(task) for ai in self.participants])
    return results
```

**3. Сборщик данных и парсер кода (Aggregator)**
Локальные модели часто возвращают текст вперемешку с кодом. Агрегатор должен извлечь блоки кода.
*   **Логика:** Ищем блоки ` ```python ... ``` `. 
*   Если блоков нет, просим "Судью" (например, самую умную модель из Council) прочитать ответы и выделить из них единый рабочий код.

### Этап 3: Автоматическое применение кода (Autonomous Dev Loop)
*Самая опасная и интересная часть. ИИ предлагает код, система его применяет, тестирует и откатывает, если что-то сломалось.*

**1. Изоляция и Git (Safety First):**
*   Перед применением кода система делает `git stash` или создает новую ветку `auto/council-task-{id}`.
*   Изменения применяются **только** в эту ветку.

**2. Pipeline применения (DevExecutor):**
1. **Extract:** Извлекаем предложенный код и пути файлов из ответов Council.
2. **Apply:** Записываем код в файлы (через стандартный Python I/O).
3. **Test:** Запускаем через `subprocess`: `py -3 -m pytest` и `py -3 scripts/check_architecture.py`.
4. **Analyze:** 
   * Если тесты **зелёные** — коммитим изменения (`git commit -m "Auto-impl by Council"`).
   * Если тесты **красные** — собираем лог ошибок pytest, отправляем обратно в Council с промптом: *"Ваш код упал с ошибкой {traceback}. Исправьте"*. (Один цикл retry).
5. **Merge:** Если после (максимум) 2 попыток тесты проходят — делаем Merge Request или Pull в основную ветку (на усмотрение пользователя через UI галочку "Auto-merge").

### Этап 4: Интеграция с ядром UNI (EventLoop)
*Чтобы человек мог запустить этот процесс голосом или текстом.*

1. Добавляем новые прямые команды в `event_loop.py`:
   * `"совет: разработай [задача]"` -> инициирует Council.
2. Добавляем Capability `uni.capabilities.dev_capability`, которая связывает `EventLoop` и `CouncilManager`.
3. **Важно (из плана v3):** Вся работа с файлами и тестами в `DevExecutor` должна использовать `async with self._tool_lock`, чтобы не конфликтовать с браузером или автономным режимом, если он запущен.

### 3. Thread Manager (`thread_manager.py`)

```python
"""Управление тредами сообщений."""

import re
from datetime import datetime
from typing import Optional, Dict

class ThreadManager:
    """Управляет тредами сообщений между UNI и ИИ."""
    
    THREAD_PATTERN = re.compile(r'\[(\d{2}-\d{2}-[A-Z]{3}-\d{4})\](.*?)\[/end-\1\]', re.DOTALL)
    
    def __init__(self):
        self.threads: Dict[str, Dict] = {}
    
    def parse_thread(self, text: str) -> Optional[Dict]:
        """Парсит сообщение с Thread ID."""
        match = self.THREAD_PATTERN.search(text)
        if not match:
            return None
        
        thread_id = match.group(1)
        content = match.group(2).strip()
        
        lines = content.split('\n')
        topic = lines[0].strip() if lines else "Без темы"
        body = '\n'.join(lines[1:])
        
        return {
            "id": thread_id,
            "topic": topic,
            "body": body,
            "timestamp": datetime.now()
        }
    
    def format_thread(self, topic: str, body: str) -> str:
        """Форматирует сообщение с Thread ID."""
        thread_id = f"{datetime.now().day:02d}-{datetime.now().hour:02d}-{topic[:3].upper()}-{datetime.now().strftime('%M%S')}"
        return f"[{thread_id}]\n{topic}\n\n{body}\n[/end-{thread_id}]"
```

### 4. Code Generator (`code_generator.py`)

```python
"""Применение кода к проекту."""

import subprocess
from pathlib import Path
from typing import List, Dict
import re

class CodeGenerator:
    """Генерирует и применяет код к проекту."""
    
    PROJECT_ROOT = Path("C:/llm/uni")
    
    async def apply_changes(self, responses: Dict[str, str], commit_message: str) -> bool:
        """Применяет изменения из ответов ИИ."""
        # 1. Извлекаем код
        files = self._extract_files(responses)
        if not files:
            print("⚠️ Нет кода для применения")
            return False
        
        # 2. Записываем файлы
        for filepath, content in files.items():
            full_path = self.PROJECT_ROOT / filepath
            full_path.parent.mkdir(parents=True, exist_ok=True)
            full_path.write_text(content, encoding="utf-8")
            print(f"✅ Записан: {filepath}")
        
        # 3. Проверка синтаксиса
        if not await self._check_syntax():
            return False
        
        # 4. Запуск тестов
        if not await self._run_tests():
            return False
        
        # 5. Коммит
        return await self._git_commit(commit_message)
    
    def _extract_files(self, responses: Dict[str, str]) -> Dict[str, str]:
        """Извлекает файлы из ответов ИИ."""
        files = {}
        pattern = r'```(\w+)\n(.*?)\n```'
        
        for name, response in responses.items():
            matches = re.findall(pattern, response, re.DOTALL)
            for lang, code in matches:
                # Ищем путь в комментарии
                path_match = re.search(r'# FILE: (.*?)\n', code)
                if path_match:
                    path = path_match.group(1)
                    content = code.replace(path_match.group(0), '')
                    files[path] = content
        
        return files
    
    async def _check_syntax(self) -> bool:
        """Проверяет синтаксис Python."""
        result = subprocess.run(
            ["python", "-m", "py_compile", str(self.PROJECT_ROOT / "uni")],
            capture_output=True
        )
        if result.returncode != 0:
            print(f"❌ Ошибка синтаксиса: {result.stderr.decode()}")
            return False
        return True
    
    async def _run_tests(self) -> bool:
        """Запускает тесты."""
        result = subprocess.run(
            ["pytest", str(self.PROJECT_ROOT / "tests"), "-v", "--tb=short"],
            capture_output=True
        )
        if result.returncode != 0:
            print(f"❌ Тесты не прошли")
            return False
        print("✅ Тесты прошли")
        return True
    
    async def _git_commit(self, message: str) -> bool:
        """Создаёт коммит."""
        subprocess.run(["git", "add", "."], cwd=self.PROJECT_ROOT)
        result = subprocess.run(
            ["git", "commit", "-m", f"🤖 AI: {message}"],
            cwd=self.PROJECT_ROOT,
            capture_output=True
        )
        if result.returncode != 0:
            print(f"⚠️ Коммит не создан: {result.stderr.decode()}")
            return False
        print(f"✅ Коммит создан: {message}")
        return True
```

```python
class BaseAIAdapter:
    name: str
    async def generate(self, prompt: str, system: str) -> AsyncGenerator[str, None]:
        raise NotImplementedError
```
*Реализации:* `LMStudioAdapter` (использует ваш `uni.brain`), `OpenAIApiAdapter`, `ClaudeApiAdapter` (чтобы подключать "внешних" участников).

**2. Менеджер Совета (Council Manager)**
Принимает задачу, делает широковещательную рассылку (broadcast) всем подключенным адаптерам асинхронно через `asyncio.gather`.
```python
# uni/council/manager.py
async def run_council(self, task: str) -> list[ParticipantResponse]:
    # Запускаем всех ИИ параллельно
    results = await asyncio.gather(*[ai.generate(task) for ai in self.participants])
    return results
```

**3. Сборщик данных и парсер кода (Aggregator)**
Локальные модели часто возвращают текст вперемешку с кодом. Агрегатор должен извлечь блоки кода.
*   **Логика:** Ищем блоки ` ```python ... ``` `. 
*   Если блоков нет, просим "Судью" (например, самую умную модель из Council) прочитать ответы и выделить из них единый рабочий код.

**1. API Эндпоинты (FastAPI):**

### Этап 3: Автоматическое применение кода (Autonomous Dev Loop)
*Самая опасная и интересная часть. ИИ предлагает код, система его применяет, тестирует и откатывает, если что-то сломалось.*

**1. Изоляция и Git (Safety First):**
*   Перед применением кода система делает `git stash` или создает новую ветку `auto/council-task-{id}`.
*   Изменения применяются **только** в эту ветку.

**2. Pipeline применения (DevExecutor):**
1. **Extract:** Извлекаем предложенный код и пути файлов из ответов Council.
2. **Apply:** Записываем код в файлы (через стандартный Python I/O).
3. **Test:** Запускаем через `subprocess`: `py -3 -m pytest` и `py -3 scripts/check_architecture.py`.
4. **Analyze:** 
   * Если тесты **зелёные** — коммитим изменения (`git commit -m "Auto-impl by Council"`).
   * Если тесты **красные** — собираем лог ошибок pytest, отправляем обратно в Council с промптом: *"Ваш код упал с ошибкой {traceback}. Исправьте"*. (Один цикл retry).
5. **Merge:** Если после (максимум) 2 попыток тесты проходят — делаем Merge Request или Pull в основную ветку (на усмотрение пользователя через UI галочку "Auto-merge").

---

### Этап 4: Интеграция с ядром UNI (EventLoop)
*Чтобы человек мог запустить этот процесс голосом или текстом.*

1. Добавляем новые прямые команды в `event_loop.py`:
   * `"совет: разработай [задача]"` -> инициирует Council.
2. Добавляем Capability `uni.capabilities.dev_capability`, которая связывает `EventLoop` и `CouncilManager`.
3. **Важно (из плана v3):** Вся работа с файлами и тестами в `DevExecutor` должна использовать `async with self._tool_lock`, чтобы не конфликтовать с браузером или автономным режимом, если он запущен.

**Главный вывод, на котором я строю план:** любая система, которая «спрашивает ИИ и автоматически пишет код», обязана иметь **слой проверки фактов о коде**. ИИ противоречат друг другу — и единственный арбитр это реальный репозиторий. Без этого слоя авто-режим будет уверенно применять фиксы к несуществующим багам (ровно то, от чего предостерегает v3).

## 2. Мой план MVP: **DevCoord** — координатор ИИ-совета

Цель: локальный интерфейс, который рассылает dev-задачу всем ИИ-участникам, собирает ответы, **проверяет их утверждения о коде**, синтезирует изменение и (под контролем) применяет его к `C:\LLM\UNI\uni`.

Принципы (из вашего же манифеста и BUILD_PLAN):
- **Внешние ИИ = предложения, а не команды.** Ничего не применяется без верификации и тестов.
- **Один канонический источник** — никаких новых деревьев; артефакты сессий в `.uni-dev/sessions/`.
- **Один билд = один проверяемый шаг.**
- **Provenance** — фиксируем, кто что сказал; никакого «консенсуса ИИ» задним числом.

```python
# devcoord/providers/openai_compat.py
from openai import AsyncOpenAI
from .base import AIProvider

class OpenAICompatProvider:
    def __init__(self, name: str, base_url: str, model: str,
                 api_key: str = "not-needed", timeout: float = 120.0) -> None:
        self.name = name
        self.model = model
        self._client = AsyncOpenAI(base_url=base_url, api_key=api_key, timeout=timeout)

    async def generate(self, prompt: str, *, system: str | None = None) -> str:
        messages = ([{"role": "system", "content": system}] if system else [])
        messages.append({"role": "user", "content": prompt})
        resp = await self._client.chat.completions.create(
            model=self.model, messages=messages, temperature=0.2)
        return resp.choices[0].message.content or ""

    async def health(self) -> bool:
        try:
            await self._client.models.list(); return True
        except Exception:
            return False
```

**Диспетчер (fan-out + изоляция сбоев одного провайдера):**

```python
# devcoord/dispatch.py
import asyncio
from .models import DevTask, ProviderResponse, ProviderStatus
from .providers.base import AIProvider

async def dispatch(task: DevTask, providers: list[AIProvider],
                   *, timeout: float = 120.0) -> list[ProviderResponse]:
    async def _call(p: AIProvider) -> ProviderResponse:
        loop = asyncio.get_running_loop(); t0 = loop.time()
        try:
            text = await asyncio.wait_for(p.generate(task.prompt), timeout)
            return ProviderResponse(p.name, task.id, ProviderStatus.OK,
                                    text=text, latency_ms=(loop.time() - t0) * 1000)
        except asyncio.TimeoutError:
            return ProviderResponse(p.name, task.id, ProviderStatus.TIMEOUT, error="timeout")
        except Exception as exc:
            return ProviderResponse(p.name, task.id, ProviderStatus.ERROR, error=str(exc))
    return await asyncio.gather(*(_call(p) for p in providers))
```

**Верификатор (урок v3 — арбитр это код, а не ИИ):**

```python
# devcoord/verify.py
from pathlib import Path
from dataclasses import dataclass
from .models import Claim

@dataclass
class Verdict:
    claim: Claim
    confirmed: bool
    detail: str

async def verify_claim(claim: Claim, repo_root: Path) -> Verdict:
    target = (repo_root / claim.file).resolve()
    if not str(target).startswith(str(repo_root.resolve())):   # защита от выхода за репо
        return Verdict(claim, False, "path escapes repo")
    if not target.exists():
        return Verdict(claim, False, "file not found")
    text = target.read_text(encoding="utf-8", errors="ignore")
    if claim.symbol is None:
        return Verdict(claim, True, "file exists")
    present = claim.symbol in text
    return Verdict(claim, present, f"'{claim.symbol}' {'found' if present else 'NOT found'} in {claim.file}")
```

**Авто-цикл разработки (с обязательными воротами):**

```python
# devcoord/loop.py
async def auto_dev(task, council, verifier, synthesizer, applier, *, max_rounds=3):
    result = None
    for rnd in range(max_rounds):
        responses = await dispatch(task, council)                    # 1. спросить совет
        verdicts  = await verifier.check(responses)                  # 2. проверить о код
        proposal  = await synthesizer.merge(verdicts)                # 3. свести в план
        result    = await applier.apply(proposal, dry_run=(rnd == 0))# 4. dry-run → apply
        if result.tests_passed:
            return result                                            # pytest+check_architecture зелёные
        task = task.with_feedback(result.test_errors)                # 5. replan по ошибкам тестов
    return result
```

**Definition of Done (MVP):**
- Интерфейс рассылает задачу ≥3 провайдерам и показывает их ответы.

- Ни одно изменение не попадает в репо без зелёных `pytest` + `check_architecture.py`.
- Есть `dry_run`, одобрение человеком и git-откат.
- Провал одного провайдера не останавливает остальных.

```python
from fastapi import FastAPI, WebSocket, HTTPException
from pydantic import BaseModel
import uvicorn
import asyncio
from datetime import datetime
from typing import List, Dict, Any
import uuid

app = FastAPI(title="UNI Coordinator", version="0.1.0")

# ----- Модели данных -----
class TaskRequest(BaseModel):
    goal: str
    team: List[str] = ["claude", "deepseek", "qwen", "chatgpt"]

@app.post("/api/task")

@app.get("/api/task/{task_id}")

    """Возвращает список всех задач."""
```

### 3. Thread Manager (`thread_manager.py`)

```python
"""Управление тредами сообщений."""

import re
from datetime import datetime
from typing import Optional, Dict

class ThreadManager:
    """Управляет тредами сообщений между UNI и ИИ."""
    
    THREAD_PATTERN = re.compile(r'\[(\d{2}-\d{2}-[A-Z]{3}-\d{4})\](.*?)\[/end-\1\]', re.DOTALL)
    
    def __init__(self):
        self.threads: Dict[str, Dict] = {}
    
    def parse_thread(self, text: str) -> Optional[Dict]:
        """Парсит сообщение с Thread ID."""
        match = self.THREAD_PATTERN.search(text)
        if not match:
            return None
        
        thread_id = match.group(1)
        content = match.group(2).strip()
        
        lines = content.split('\n')
        topic = lines[0].strip() if lines else "Без темы"
        body = '\n'.join(lines[1:])
        
        return {
            "id": thread_id,
            "topic": topic,
            "body": body,
            "timestamp": datetime.now()
        }
    
    def format_thread(self, topic: str, body: str) -> str:
        """Форматирует сообщение с Thread ID."""
        thread_id = f"{datetime.now().day:02d}-{datetime.now().hour:02d}-{topic[:3].upper()}-{datetime.now().strftime('%M%S')}"
        return f"[{thread_id}]\n{topic}\n\n{body}\n[/end-{thread_id}]"
```

### 4. Code Generator (`code_generator.py`)

```python
"""Применение кода к проекту."""

import subprocess
from pathlib import Path
from typing import List, Dict
import re

class CodeGenerator:
    """Генерирует и применяет код к проекту."""
    
    PROJECT_ROOT = Path("C:/llm/uni")
    
    async def apply_changes(self, responses: Dict[str, str], commit_message: str) -> bool:
        """Применяет изменения из ответов ИИ."""
        # 1. Извлекаем код
        files = self._extract_files(responses)
        if not files:
            print("⚠️ Нет кода для применения")
            return False
        
        # 2. Записываем файлы
        for filepath, content in files.items():
            full_path = self.PROJECT_ROOT / filepath
            full_path.parent.mkdir(parents=True, exist_ok=True)
            full_path.write_text(content, encoding="utf-8")
            print(f"✅ Записан: {filepath}")
        
        # 3. Проверка синтаксиса
        if not await self._check_syntax():
            return False
        
        # 4. Запуск тестов
        if not await self._run_tests():
            return False
        
        # 5. Коммит
        return await self._git_commit(commit_message)
    
    def _extract_files(self, responses: Dict[str, str]) -> Dict[str, str]:
        """Извлекает файлы из ответов ИИ."""
        files = {}
        pattern = r'```(\w+)\n(.*?)\n```'
        
        for name, response in responses.items():
            matches = re.findall(pattern, response, re.DOTALL)
            for lang, code in matches:
                # Ищем путь в комментарии
                path_match = re.search(r'# FILE: (.*?)\n', code)
                if path_match:
                    path = path_match.group(1)
                    content = code.replace(path_match.group(0), '')
                    files[path] = content
        
        return files
    
    async def _check_syntax(self) -> bool:
        """Проверяет синтаксис Python."""
        result = subprocess.run(
            ["python", "-m", "py_compile", str(self.PROJECT_ROOT / "uni")],
            capture_output=True
        )
        if result.returncode != 0:
            print(f"❌ Ошибка синтаксиса: {result.stderr.decode()}")
            return False
        return True
    
    async def _run_tests(self) -> bool:
        """Запускает тесты."""
        result = subprocess.run(
            ["pytest", str(self.PROJECT_ROOT / "tests"), "-v", "--tb=short"],
            capture_output=True
        )
        if result.returncode != 0:
            print(f"❌ Тесты не прошли")
            return False
        print("✅ Тесты прошли")
        return True
    
    async def _git_commit(self, message: str) -> bool:
        """Создаёт коммит."""
        subprocess.run(["git", "add", "."], cwd=self.PROJECT_ROOT)
        result = subprocess.run(
            ["git", "commit", "-m", f"🤖 AI: {message}"],
            cwd=self.PROJECT_ROOT,
            capture_output=True
        )
        if result.returncode != 0:
            print(f"⚠️ Коммит не создан: {result.stderr.decode()}")
            return False
        print(f"✅ Коммит создан: {message}")
        return True
```
