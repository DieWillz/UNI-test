# Управление ПК под зрением (Computer-Vision Control)

Краткое руководство пользователя по функции «Юни видит экран → кликает → проверяет».

## Что это
Юни может управлять вашим компьютером «на глаз»: находит элемент на экране
через зрение (VLM / локальный UIA-fallback), кликает человеко-подобно
(через `human_mouse`), затем проверяет результат повторным анализом экрана.
Замкнутый цикл: **вижу → сделала → проверила**.

## Как включить

1. Запустите веб-панель UNI:
   ```
   cd C:\LLM\UNI
   set PYTHONPATH=C:\LLM\UNI
   C:\LLM\python312\python.exe -m uni --webui
   ```
   (или ваш штатный способ запуска сервера на порту 8787).
2. Откройте панель в браузере → вкладка **«Компьютер»**.
3. Введите цель в поле (например, «открой блокнот») и нажмите **«Выполнить»**.
4. В логе шагов вы увидите промежуточные состояния:
   `вижу → сделала (клик) → проверила (достигнуто ✅)`.

Голосом (через обычный ввод/микрофон): скажите **«Юни, открой блокнот»** —
фраза с глаголом `открой / кликни / нажми / запусти` перехватывается и
направляется в цикл управления ПК (без правки ядра LLM).

## Как остановить
- В панели: кнопка **«СТОП»** на вкладке «Компьютер» (немедленно прерывает цикл).
- Голосом/текстом: команда стоп (как и для других режимов).

Остановка — fail-closed: клик не производится после сигнала СТОП, курсор
остаётся на месте.

## Как откалибровать (DPI / мульти-монитор)
Если клики приходятся мимо цели на масштабированном дисплее (DPI 125%/150%)
или втором мониторе:

1. Профиль калибровки генерируется автоматически при первом запуске
   человеко-подобной мыши и сохраняется в
   `uni/memory/calibration/mouse_display_profile.json` (runtime, не коммитится).
2. Он сопоставляет логические координаты (из зрения) с физическими
   (win32api.SetCursorPos) с учётом DPI и смещения мониторов.
3. Если нужно **выключить** калибровку (вернуть старое поведение) — задайте
   переменную окружения перед запуском:
   ```
   set UNI_NO_DISPLAY_CALIBRATION=1
   ```

## Безопасность
- **Blacklist**: цели, содержащие системные команды (`format`, `del`, `taskkill`,
  `shutdown`, `powershell`, `bcdedit`, `net stop`, …), блокируются — клик не
  производится. Fail-closed.
- **Системные зоны**: клик в отступе 40px от краёв экрана (панель задач/
  уведомления Windows) блокируется, если передан размер экрана.
- Локальный fallback (UIA/OCR) включается опцией `vision.local_fallback_enabled`
  в `config.yaml` — используется, когда VLM (LM Studio) недоступна.

## Настройки (config.yaml)
```yaml
capabilities:
  vision:
    enabled: true
    local_fallback_enabled: false   # true -> UIA/OCR когда VLM упала
  computer:
    use_human_motion: true          # человеко-подобные движения мыши
```

## Архитектура (где код)
- `uni/tools/visual_action.py` — оркестрация цикла (не capability).
- `uni/human_mouse.py` — человеко-подобная мышь + калибровка.
- `uni/tools/display_calibration.py` — DPI/мульти-монитор.
- `uni/tools/local_vision_fallback.py` — UIA/OCR fallback.
- `uni/tools/trajectory_store.py` — сохранение успешных траекторий.
- `uni/webui/` — вкладка «Компьютер» + `/api/computer/{act,stop,status}`.
- `uni/event_loop.py` — голосовая маршрутизация «открой X».
