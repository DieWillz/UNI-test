# Чат Юни — проверка 2026-08-28

Область: продолжение незавершённых правок Hermes в каноническом WebUI.

## Внесённые правки

- Подключён работающий модуль чата; выбор роли сверяется с ответом сервера.
- Добавлены предпросмотр камеры, явная отправка кадра и вложение JPEG/PNG/WebP.
- WebP преобразуется в PNG: локальный LM Studio воспроизводимо отвергал WebP ошибкой `400: 'url' field must be a base64 encoded image`.
- POST кадра/остановки камеры дочитывает тело запроса. До исправления следующий запрос в том же соединении получал HTML с HTTP 501.
- Показаны фаза и последняя команда устройства; они не выдаются за физическое измерение.
- Явная команда `мощность 25%` проходит через Intiface, с проверкой лимита и STOP.txt, без браузера XToys.
- Реплики автономной сессии попадают в чат; повторная озвучка не запускается.
- Озвучка чата читает audio_url; отключение серверной озвучки ограничено текущим запросом и не меняет конфиг.
- Обычные ответы больше не сопровождаются отдельным сообщением not_verified. Для действий защита подтверждения сохранена.
- Предыдущий TaskOutcome не переиспользуется для нового запроса.

## Наблюдения и границы проверки

- 27 целевых проверок сервера и настоящих DOM/скриптов прошли с изолированными транспортами. Реальную камеру/устройство они не включают.
- Ещё 11 проверок инварианта, выбора модели и кодирования камеры прошли; скрипт check_verification_invariant.py — PASS.
- Известные предупреждения окружения: отсутствует pytest-timeout, устаревшие импорты websockets.
- Локальная модель распознала синтетический красный квадрат. На другом синтетическом изображении после исправления формата попросила предоставить изображение. Поэтому устойчивое визуальное распознавание пока НЕ подтверждено; отсутствие HTTP-ошибки само по себе недостаточно.
- Живая проверка страницы заблокирована политикой встроенного браузера. Обход не выполнялся.
- Физическое движение устройства, кадр реальной камеры и слышимый звук не проверены агентом.
